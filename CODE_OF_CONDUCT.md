# Code of conduct

muscles follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, and keep discussion about the work.
Harassment and personal attacks aren't welcome in issues, pull requests or
anywhere else in the project.

Report unacceptable behavior privately through a
[security advisory](https://github.com/rossedman/muscles/security/advisories/new)
(it reaches the maintainer directly), and it will be handled promptly and
confidentially.
