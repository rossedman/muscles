The problem

Every image is a stack of diffs.
Nobody reads them.

docker history gives you commands and sizes. What each layer actually put on disk, and what it left behind, takes an export, a pile of tarballs and an afternoon.

muscles replays the layers over a merged filesystem and tells you, per layer, what changed, where the bytes went, and what's worth fixing.

Four kinds of change

Every path, classified.
Every hidden byte, accounted for.

Each entry in a layer is compared with the filesystem below it. Waste is every byte a layer stores that a later layer hides, with both layers named.

+Added

The path didn't exist in any lower layer.

~Modified

The path existed below with different contents. The old copy is still stored: waste.

◌Rewritten

The same contents stored again, only permissions or owner changed. The classic chown -R tax.

-Deleted

A whiteout hid the path. The bytes are still in the layer that stored them.

In CI

Budgets in a file.
A red build when they break.

Commit a .muscles.yaml next to your Dockerfile. muscles images check exits 5 when the image is too big, wastes too much, grew too fast against the main branch, or ships a path you forbid, like **/.env.

  • {% include ".icons/material/docker.svg" %} No Docker socket needed: reads tarballs, OCI layouts and registries
  • {% include ".icons/material/github.svg" %} GitHub annotations and Markdown for the job summary

# .muscles.yaml
check:
  max_size: 800MB
  max_waste: 50MB
  max_growth: 5%
  forbid: ["**/.env", "**/.git/"]
$ muscles images check app.tar --baseline ghcr.io/acme/app:main

Why muscles

Small, fast, honest.
Built for people and pipelines.

{% include ".icons/material/cloud-download-outline.svg" %}

Registry images without pulling

Layers stream straight from the registry and are read once. Auth comes from your Docker config and credential helpers, never from flags.

{% include ".icons/material/lightning-bolt.svg" %}

A cache that never goes stale

Layer indexes are keyed by content digest. A base image is read once and every image built on it opens instantly.

{% include ".icons/material/compare-horizontal.svg" %}

Release diffs

muscles images diff shows the layers two images share, the size of each one that differs, and every path that changed.

{% include ".icons/material/console.svg" %}

Follows CLI Style

Noun-verb commands, typed streams, documented exit codes, --json everywhere, real examples in every help page, and help --json for agents.

{% include ".icons/material/shield-lock-outline.svg" %}

Nothing leaves your machine

No telemetry. The only network calls are reads from the registries you name.

{% include ".icons/material/package-variant-closed.svg" %}

One static binary

No cgo, no runtime, no Docker. Released for macOS, Linux and Windows with completions and a man page.

Quick start

From an image to an answer
in three commands.

Point muscles at anything that holds an image: a local tag, a registry reference, a tarball or an OCI directory. No config file needed.

{% include ".icons/material/book-open-page-variant-outline.svg" %} Full getting-started guide

  1. Install

    $ brew install rossedman/tap/muscles

  2. Ask what to fix first

    $ muscles python:3.12-slim
$ muscles layers list python:3.12-slim

  3. Open the layer that surprised you

    $ muscles changes list python:3.12-slim --layer 2
$ muscles waste list python:3.12-slim
